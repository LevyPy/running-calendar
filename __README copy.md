## 🛠️ Maintenance Tips

1. **Adding a new upcoming race:**
   - Add a new row to the "Upcoming Races" table
   - Use the status emoji: ⏳ Planning, 🔍 Considering

2. **Registering for a race:**
   - Move the race from "Upcoming Races" to "Registered Races"
   - Add bib number when available
   - Use the status emoji: ✅ Registered

3. **Completing a race:**
   - Move the race to the appropriate year section under "Completed Races"
   - Fill in all details including times, placement, and links
   - Update Personal Records section if applicable

4. **Adding a new performance goal:**
   - Add to the appropriate distance section under "Performance Goals"
   - Use status emoji: 🎯 Goal, ✅ Achieved

5. **Yearly organization:**
   - Keep the most recent year's section open by default (`<details open>`) 
   - Collapse older years to keep the document tidy
