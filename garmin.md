# ⌚ Garmin Device Configurations

*Centralized documentation for Garmin watch settings and data screens*

## 🔧 General Setup Instructions

1. Pair heart rate strap
2. Change GPS recording from "smart" to "every second"

## 🛠️ Maintenance Tips

1. **Adding a new device:**
   - Create a new section using the `<details>` tag format
   - Include data fields and data screens subsections

2. **Updating device configurations:**
   - Modify the appropriate device section
   - Keep the same structure for consistency

3. **Best practices:**
   - Document any changes to your watch configuration
   - Note which configurations work best for different race types
   - Consider adding screenshots in the future (store in an `img` folder)
